# RM BattleScope v1.0.0

本阶段正式开源版本提供比赛检索、轨迹回放、个人战绩页和v3.2自定义职责评分。版本号描述软件发布状态，不代表评分经过官方认可或录像人工校准。

- 对英雄、工程、步兵、哨兵、空中、飞镖、雷达按可观测贡献生成分项与依据。证据不足时暂不评级，不计入最高分或队伍均分；均分显示统计分母。
- 伤害来源分开显示原始事件、高可信归因、中可信归因、低可信分摊与未归因。受击总量与逐目标分项守恒，低可信仅用于折算输出贡献。
- 常用播放、倍速与时间轴集中在地图上方；复杂筛选收进设置。能量机关连续记录合并为可展开原始记录的过程，关键事件支持检索与上下文跳转。
- 输出根目录支持环境变量和忽略的本地配置，CLI可通过`--output-dir`覆盖。复盘依赖只包含NumPy、Matplotlib和Pillow。
- 静态回放与本地后端明确区分；静态JSON使用浏览器下载，CSV与CLI共用导出格式，相对目录链接适配项目子路径。

默认纳入一个新静态示例：东部第27场第2局，浙江大学对东南大学，game_id 1779427046868。此前北部第90场示例保留为历史版本，不作为最新版评分案例。普通生成回放、本地照片、数据库、训练集、权重、缓存与个人脚本不纳入发布。历史生成产物仅从版本库当前树移除，本机文件保留，旧提交历史不重写。

评分仍是自定义启发式。高可信不等于官方确认；压制、地形骚扰和掩护只表示可回看的观测迹象。工程运输、兑换等职责缺少完整数据，未观测贡献不代表没有贡献。没有同步视频和人工标签时，分布诊断不能证明准确率，也不能支持随意调整权重。离线强化学习研究代码和训练产物不属于本次已验收发布范围。
